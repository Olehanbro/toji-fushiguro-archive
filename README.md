# Toji Fushiguro Archive

Атмосферний український фан-сайт про Тоджі Фушіґуро з «Магічної битви».

## Локальний запуск

```bash
pnpm install
pnpm dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Технології

- Next.js
- React
- TypeScript
- CSS

## Правовласники

Це неофіційний некомерційний фан-проєкт. Права на персонажа та «Jujutsu Kaisen» належать Ґеґе Акутамі, Shueisha та відповідному виробничому комітету.
